# Portfolio — Majo

Małe portfolio w jednym pliku `index.html` (bez frameworków, bez builda).

## Projekty

- **Budżet** (`budzet-standalone.html`) — miesięczny budżet w przeglądarce: wydatki w kategoriach, ile zostało i do kiedy starczy przy obecnym tempie. Dane w `localStorage`.

## Jak opublikować na GitHub Pages

1. W repozytorium wejdź w **Settings → Pages**.
2. W **Source** wybierz *Deploy from a branch*, gałąź `main`, folder `/ (root)`.
3. Po chwili strona będzie pod adresem `https://majo17245.github.io/Bud-ett-/`.

## Jak edytować

Wszystko jest w `index.html`:
- imię i opis — sekcja `<header class="hero">`
- projekty — kopiuj blok `<article class="project">`
- umiejętności — lista `<ul class="skills">`
- kontakt — sekcja `<section class="contact">`
